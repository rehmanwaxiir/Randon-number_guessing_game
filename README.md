
# Python Random Number Generator

A simple random number generator built with Python. The program generates a random number within a range specified by the user.

## Features

- Allows users to enter a minimum number(1)
- Allows users to enter a maximum number(100)
- Generates a random number within the selected range
- Handles invalid numeric input
- Simple command-line interface

## Requirements

- Python 3
- No external libraries required

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Run the program:

   ```bash
   python Guess_number_game.py
   ```

   On Windows, you can also try:

   ```bash
   py Guess_number_game.py
   ```

4. Enter the minimum and maximum values when prompted.
5. The program displays a randomly generated number.

## Python Concepts Used

- Variables and data types
- User input and output
- `random` module
- Type conversion
- Exception handling
- Basic programming logic
